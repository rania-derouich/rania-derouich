## 🧬 About Me

I build computational pipelines that bridge biological data and machine learning — from raw genomic sequences to 3D protein structures and drug-binding predictions. My work spans both classical and quantum approaches to biomedical problems.

- 🧠 Quantum ML with **PennyLane** — angular, amplitude & hybrid encoding strategies
- 💊 Structural bioinformatics — homology modeling, molecular docking, MD simulation
- 📊 Genomics — gene expression analysis, RNA-seq, GTEx data visualization
- 🐍 Primary stack: **Python**, **R**, **Bash**

## 📂 Projects

### 🔬 Structural Bioinformatics & Drug Design

| Project | Description | Tools |
|---|---|---|
| [**homology-modeling-alpha-amylase**](https://github.com/rania-derouich/homology-modeling-alpha-amylase) | Comparative structural modeling of α-amylase from *P. haloplanktis* (Antarctic bacterium) — full pipeline from template search to quality validation (RMSD 0.728 Å) | MODELLER · PyMOL · SWISS-MODEL · ProSA |
| [**molecular-docking-vina**](https://github.com/rania-derouich/molecular-docking-vina) | Molecular docking of Kaempferol & Myricetin flavonoids against a target receptor — binding affinity prediction with AutoDock Vina | AutoDock Vina · PyMOL · Bash |
| [**molecular-dynamics-analysis**](https://github.com/rania-derouich/molecular-dynamics-analysis) | MD trajectory analysis — RMSD, RMSF, radius of gyration, PCA, thermodynamic properties | pytraj · NumPy · Matplotlib · AMBER |

### 🤖 Machine Learning & AI

| Project | Description | Tools |
|---|---|---|
| [**breast-cancer-ml-classification**](https://github.com/rania-derouich/breast-cancer-ml-classification) | Classical ML pipeline for breast cancer diagnosis — Random Forest, Gradient Boosting, Neural Network, Ensemble voting on the Wisconsin dataset | scikit-learn · TensorFlow · Keras |
| [**dermaai-ph2**](https://github.com/rania-derouich/dermaai-ph2) | Hybrid CNN (MobileNetV2 + VGG16) + Random Forest for dermoscopic skin lesion classification on the PH2 dataset | TensorFlow · Keras · scikit-learn |
